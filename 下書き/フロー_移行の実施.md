### 振り返りの観点

課題一覧に登録したものは、「移行の準備」の「B. 随時の修正」で手順書・資産に落とし込む。

| 観点 | 振り返ること | 例 |
|---|---|---|
| 急ごしらえ | 当日や前日に、急いで作ったり直したりした手順はないか | 前日作業の手順を、急ごしらえで整理した |
| 口頭で済ませた作業 | 手順書にないまま、口頭の説明やその場の判断で行った作業はないか | 新システムのハードコピーの自動取得を、突貫で行った |
| エラーと説明 | エラーが出たとき、原因と影響の説明はどうだったか。次に同じことが起きたら、作業者が説明できるようにしておけるか | |
| 時間 | タイムチャートどおりに進んだか。押したところはどこか | |
